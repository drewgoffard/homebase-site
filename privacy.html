Privacy policy

Last updated October 26, 2026

Homebase is software that a family runs on its own device at home (usually a Raspberry Pi connected to a screen). This Google app exists only so that this family's Homebase screen can show and update its own Google calendars.

What Homebase accesses

When a family member signs in with Google, Homebase asks for permission to:

  • see the list of their calendars, so they can choose which ones appear on the screen;
  • read, add, change and delete calendar events, so events can be shown and edited on the screen;
  • see their email address, so the screen can show which account is connected.

Where the data goes

Calendar data travels only between Google and the Homebase device in the family's home. It is stored on that device so the screen keeps working when the internet is down. Sign-in tokens are encrypted on the device.

There is no Homebase server or cloud service. The publisher of this app does not receive, collect or store any calendar data, email addresses or tokens, and nothing is sold, shared or used for advertising.

The sign-in relay page on this site, if used, only forwards the browser back to the Homebase screen on the family's home network. It stores nothing.

Google API Services User Data Policy

Homebase's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Disconnect the account in Homebase (Settings, Calendars), or remove "Homebase" at myaccount.google.com/permissions. Deleting the data on the Homebase device removes everything it stored.

Contact

Questions: the email address listed as this app's support contact on the Google sign-in screen.
